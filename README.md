# Executor Pilot Target

Kontrolowane repozytorium szkoleniowo-testowe dla projektu `litrgratis-pixel/Executor`.

Repo ma służyć wyłącznie do sprawdzenia pionowego przepływu Executora na małym, deterministycznym projekcie Python. Nie jest produktem, platformą ani dowodem wartości biznesowej Executora.

Pełna baza kodu, testów i przypadków pilota powstaje w osobnym draft PR.
